// Freeware — VBE Add-in for VBA Developers

VBE Forge Import無料

フォルダのVBAソースを、VBAプロジェクトへ一括インポート

VBE（Visual Basic Editor）のメニューから、指定フォルダにある .bas / .cls / .frm を 現在開いている VBA プロジェクトへまとめて取り込みます。 1つずつ「ファイルのインポート」を繰り返したり、同名モジュールを手で削除してから取り込み直したりする手間がなくなり、 Git などで管理している VBA ソースをブックへ書き戻す作業が簡単になります。

Windows 10 / 11 Excel 2016 以降 32bit / 64bit 両対応 管理者権限 不要 .NET Framework 4.8 MIT License
無料ダウンロード 使い方を見る

Version 1.0.1  /  ZIP 50 KB  /  2026.10.22 公開

書き出し（エクスポート）には姉妹ソフト VBE Forge Export をご利用ください。

// Features

VBE Forge Import の特長

「管理しているソースをブックへ戻したい」を、安全に、少ない手数で行うためのアドインです

フォルダ内のソースを一括インポート

指定フォルダ直下の .bas / .cls / .frm（.frx を含む）をまとめて取り込みます。フォルダに無いモジュールを削除することはありません。

同名モジュールは自動で置き換え

Module11 のような別名で増えることはありません。モジュール名はファイル内の Attribute VB_Name で決まります。置き換えに失敗した場合は元のモジュールを残します。

実行前に一覧で確認・選択

ファイルごとに「追加／置き換え／コード差し替え／スキップ」を一覧表示します。各行のチェックボックスで取り込む対象を選べ、［すべて選択］［すべて解除］でまとめて切り替えられます。

ThisWorkbook / Sheet1 のコードも

ドキュメントモジュールは、既存のシート・ブックのコードだけをファイルの内容で差し替えます（オプション）。シート自体は作成せず、対応するシートが無いものはスキップします。

保存しなければ元に戻せる

取り込んだ内容はブックを保存するまで確定しません。結果に問題があれば、ブックを保存せずに閉じれば取り込む前の状態に戻ります。

管理者権限不要・商用利用も無償

登録先は現在のユーザー配下（HKCU）のみ。32bit・64bit どちらの Excel でも動作します。MITライセンスのフリーソフトで、業務利用を含め無償です。

// How it works

フォルダを選んで、一覧を確認して、実行

VBE Forge Export で書き出したフォルダを、そのまま取り込み元として使えます

確認画面のイメージ：C:\Work\PG_VBA\
選択処理モジュール名ファイル

☑置き換えModule1Module1.bas

☑置き換えfrmMainfrmMain.frm

※ 画面の一例です。clsDatabase はチェックを外して取り込まない例、Sheet2 は取り込み先に対応するシートが無いため選択できない例です。

1

取り込み先のブックを開き、VBE を開く

ブックを開いて Alt + F11 を押し、プロジェクトエクスプローラーで取り込み先の VBA プロジェクトを選択します。

2

アドイン → VBE Forge Import

取り込み元フォルダを指定して［次へ］をクリックします。前回のフォルダを記憶しており、初回は Export の出力先が初期値になります。

3

一覧で確認・選択してインポート実行

ファイルごとの処理内容を確認し、取り込む対象をチェックボックスで選んで［インポート実行］をクリックします。完了すると追加・置き換え・スキップの件数が表示されます。

4

問題がなければブックを保存

保存するまで取り込みは確定しません。元に戻したいときは、保存せずに閉じてください。

// Usage

導入と使い方

コマンド入力は不要です。同梱の install.bat をダブルクリックするだけで登録できます

1. インストール

ZIP を任意のフォルダへ展開し（例：C:\Tools\VBEForge.Import\）、Excel をすべて終了してから install.bat をダブルクリックします。黒い画面が開くので、案内に従って Enter キーを押すと登録が始まり、 「インストールが完了しました。」と表示されたら閉じてください。Excel を起動して VBE（Alt + F11）を開くと、 アドイン メニューに VBE Forge Import が追加されています。

登録後に展開したフォルダを移動しないでください。 移動した場合は install.bat を再度実行してください。 VBE Forge Export と同じ PC に並べてインストールできます。

2. VBAプロジェクトへのアクセスを許可する

VBA プロジェクトを書き換えるために、Excel 側の信頼設定が必要です。設定後は Excel を再起動してください。

Excel の設定 
[ファイル]
 → [オプション]
 → [トラストセンター]
 → [トラストセンターの設定]
 → [マクロの設定]
 → 「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」にチェック

設定が無効な場合、本アドインはこの手順を案内するメッセージを表示して安全に終了します。

3. インポートを実行する

VBE（Alt + F11）で取り込み先のプロジェクトを選択し、アドイン → VBE Forge Import をクリックします。 最初のダイアログで指定できる内容は次の通りです。

項目内容
取り込み元フォルダ直接入力するか「参照...」で選択します。前回のフォルダを記憶し、初回は VBE Forge Export の出力先を初期値にします。
ドキュメント
モジュールの
コードも取り込む		ThisWorkbook や Sheet1 など、既にあるシート・ブックのコードをファイルの内容で置き換えます。シート自体は作成しません（既定は ON）。
バージョン情報製品名・バージョン・発行元を表示します。

［次へ］をクリックすると取り込みの一覧が表示されます。

4. 取り込む対象を選んで実行する

一覧の各行のチェックボックスで、取り込む対象を選べます。最初は取り込めるものがすべて選ばれています。 ［すべて選択］［すべて解除］でまとめて切り替えられます。スキップの行（取り込めないもの）は選べません。

内容を確認して［インポート実行］をクリックしてください。チェックを外した行は取り込まれず、結果ではスキップとして数えられます。 完了後、結果に問題がなければブックを保存します。

取り込みの動作

状況処理
新しいモジュール追加します
同名のモジュールがある置き換えます（名前は変わりません）。置き換えに失敗した場合は元のモジュールを残します
ThisWorkbook / Sheet1 などコードだけを差し替えます（オプション）
対応するシートが無い取り込みません（スキップ）
フォルダに無いモジュール何もしません（削除しません）
一覧でチェックを外した行取り込みません（結果ではスキップとして数えます）

モジュール名は、ファイル名ではなくファイル内の Attribute VB_Name から決まります。VBE 標準のインポートと同じ動作です。 UserForm（.frm）は、同じ名前の .frx が同じフォルダに必要です。

元に戻したいとき

取り込んだ内容は、ブックを保存するまで確定しません。結果に問題があった場合は、ブックを保存せずに閉じてください。 次に開いたときは、取り込む前の状態に戻っています。大切なブックは、あらかじめバックアップを取ってからご使用ください。

ロックされたVBAプロジェクトについて

パスワードで保護（ロック）されたプロジェクトには取り込めません。 VBE でロックを解除してから実行してください。

アンインストール

Excel をすべて終了してから uninstall.bat をダブルクリックします。 展開したフォルダは手動で削除してください。ログと設定は %LOCALAPPDATA%\VBEForge\ に残るため、不要な場合は削除してください （VBE Forge Export と共用です。Export も使っている場合は残してください）。 レジストリはインストール時に書き込んだキーのみを削除し、VBE Forge Export を含む他のソフトウェアには影響しません。

うまく動かないとき

メニューに表示されない場合は、Excel を完全に終了してから登録し直してください。 VBE の アドイン → アドイン マネージャー に VBE Forge Import があるか確認し、「ロード/アンロード」にチェックを入れてください。 動作ログは %LOCALAPPDATA%\VBEForge\Logs\VBEForge_yyyyMMdd.log に記録されます。
