// Freeware — e-Gov Document ZIP Viewer

eGovViewer無料

e-Gov の電子公文書・電子通達 ZIP を、展開せずにそのまま表示

e-Gov（電子政府の総合窓口）の電子申請で受け取った公文書・電子通達の ZIP ファイルを開き、 中の通知書をそのまま表示・印刷・PDF 保存できる Windows ソフトです。 日本年金機構の「保険料納入告知額・領収済額通知書」のように、ZIP を展開してブラウザで XML を開く……という手間がかかる文書も、 ダブルクリックひとつで読めます。

Windows 10 / 11 32bit / 64bit 両対応 インストール不要 印刷・PDF 保存 フリーソフト

// Features

eGovViewer の特長

e-Gov から届いた ZIP を「開く・読む・残す」までを、ひとつのソフトで

ZIP を展開せずに表示

鑑（かがみ）文書、XML＋XSL 形式の通知書、PDF、CSV を表示します。左の一覧から文書を選ぶだけで、鑑の中のリンクからも各文書を開けます。

プレビュー付きで印刷

［印刷］で印刷プレビューを表示し、プリンターを選んで印刷できます。表示中の文書をそのまま紙に残せます。

PDF 保存（A4・A3・B4 縦横）

［PDF 保存］で表示中の文書を PDF ファイルに保存します。用紙は A4・A3・B4 の縦／横から選べます（既定 A4 縦）。

元ファイルの取り出し

ZIP 内のファイル（CSV など）を取り出して保存できます。表計算ソフトでデータを使いたいときに便利です。

コマンドラインで一括 PDF 出力

/pdf を付けて起動すると、画面を出さずに ZIP 内のすべての文書を PDF に保存して終了します。バッチ処理や定型業務の自動化に。

インストール不要・ディスクに残さない

exe 単体で動作し、レジストリも使いません。ZIP の内容は一時ファイルとしてディスクに展開せず、メモリ上で処理します。

// Usage

使い方

ダウンロードした ZIP を展開し、eGovViewer.exe を任意のフォルダに置いて実行するだけです

1

ZIP ファイルを開く

eGovViewer.exe を起動し、［開く］で e-Gov から届いた ZIP ファイルを選択します。次の方法でも開けます。

  • ZIP ファイルをウィンドウにドラッグ＆ドロップ
  • ZIP ファイルを eGovViewer.exe のアイコンにドラッグ＆ドロップ
  • ZIP ファイルを右クリック →［プログラムから開く］で eGovViewer.exe を選択
2

文書を選んで表示

左の一覧から文書を選ぶと、右側に表示されます。鑑の中のリンクをクリックしても各文書を開けます。

3

印刷する

［印刷］で印刷プレビューが表示されます。プリンターを選んで印刷してください（プリンターに「PDF に保存」を選ぶと PDF として保存することもできます）。

4

PDF に保存する

［PDF 保存］で表示中の文書を PDF ファイルに保存します。用紙サイズ・向きはツールバーの［用紙］で選べます（既定 A4 縦）。

ショートカットキー

キー動作
Ctrl+O開く
Ctrl+P印刷
Ctrl+SPDF 保存
Alt+← ／ Alt+→戻る ／ 進む
Ctrl+マウスホイール拡大・縮小

コマンドライン

コマンドプロンプト 
REM 指定した ZIP ファイルを開く
eGovViewer.exe [ZIPファイル]

REM 画面を表示せずに、ZIP 内のすべての文書を PDF に保存して終了
eGovViewer.exe ZIPファイル /pdf [出力フォルダ] [/paper:用紙]

出力フォルダを省略すると、ZIP ファイルと同じフォルダに保存します。 用紙は A4縦 A4横 A3縦 A3横 B4縦 B4横 から指定します（既定 A4縦）。 終了コードは 0 が成功、1 が失敗です。

// First launch

「Windows によって PC が保護されました」と表示される場合

本ソフトはコード署名（有料の電子証明書）を行っていないため、インターネットから入手した直後は Windows の SmartScreen 機能により上記の警告が表示されることがあります。ソフトに問題があるわけではありません。 次のどちらかの方法で起動できます。

方法 1

警告画面から実行する

  1. 警告画面の［詳細情報］をクリックします。
  2. 表示された［実行］ボタンをクリックします。

次回からは警告なしで起動できます。

方法 2

ZIP のブロックを解除してから展開する

  1. ダウンロードした ZIP ファイルを右クリックし、［プロパティ］を開きます。
  2. ［全般］タブ下部の「セキュリティ」欄にある［許可する］にチェックを入れ、［OK］をクリックします。
  3. ZIP ファイルを展開し直してから eGovViewer.exe を起動します。
必ず当社 Web サイト（rapid-apps.co.jp）またはベクターから入手したファイルでお試しください。 それ以外の場所から入手したファイルは実行しないでください。 ダウンロードしたファイルは、ダウンロード欄の SHA-256 値で改ざんの有無を確認できます。
