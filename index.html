// For SIers & Development Companies

現場の課題に、技術で応える。

大規模な開発体制を組むほどではない作業も、課題と必要な範囲を確認して進めます。

01

担当者が退職したシステムを調べたい

仕様書が不足していても、ソースコードとデータから現状を把握したい。

02

VB6の既存システムを改修したい

全面刷新を前提とせず、必要な機能の追加や障害修正を依頼したい。

03

Accessで作成したシステムを移行したい

フォーム・クエリ・VBAとデータ構造を調査し、既存業務を踏まえて段階的に新しい環境へ移行したい。

04

SQLの実行時間を短縮したい

実行計画やデータの状態を調べ、処理遅延の原因を確認したい。

05

PL/SQL・夜間バッチを改善したい

処理の流れとSQLを見直し、業務時間に影響する遅延を改善したい。

06

Excel・CSVの取込を自動化したい

手作業で行っている取込・変換・チェックをバッチ処理にまとめたい。

07

販売管理と別システムを連携したい

CSVやAPIを使い、業務システム間のデータ受け渡しを実装したい。

08

Oracleのデータ移行・不整合を調べたい

移行対象のデータや処理を確認し、変換・照合の方法を整理したい。

09

開発案件のDB処理だけを外注したい

設計・実装やSQL調査など、手が足りない部分を任せたい。

10

テーブル設計をDBに詳しい人に任せたい

業務要件に合わせ、データの整合性・処理性能・将来の拡張を考慮したテーブル構成やキー、インデックスを設計したい。

小規模な改修・部分受託にも対応

システム全体の開発だけでなく、SQLの調査、既存プログラムの部分改修、データ変換処理の作成など、範囲を限定した作業にも対応しています。既存プロジェクトの一部分を外部技術者に任せたい場合もご相談ください。

スポット対応、リモートでの作業、継続的な技術支援についても、対象環境・作業範囲・ご希望の時期を確認して進め方をご案内します。

// Services

必要な部分を支える、3つのサービス

調査から改善・実装まで、既存システムの構造と運用制約を踏まえて支援します。

01 / DATABASE

データベース性能改善

Oracleの専門知識を活かし、調査から改善まで支援

データベース性能改善の中でも、特にOracleを得意としています。SQL・PL/SQLやバッチ処理の遅延原因を、実行計画やデータの状態から調査し、改善方法を検討します。既存システムの構造、データ量、運用制約を確認し、変更の影響と検証・切り戻しの手順を考慮して進めます。

  • SQL実行計画の調査・分析、SQLチューニング
  • PL/SQL改修・夜間バッチ処理の性能改善
  • インデックス・統計情報・パーティションの調査
  • データ不整合・処理遅延の原因調査
  • 改善前後の検証と結果の共有
データベース性能改善を相談する
02 / APPLICATION

既存業務システムの調査・改修

全面刷新を前提とせず、既存資産を活かした改善

VB6・VBA・C#などの既存ソースコードを調査し、必要な範囲を改修します。レガシーシステムの保守・延命に加え、現状と影響範囲を整理したうえで段階的な移行も支援します。

  • 既存システム調査・ソースコード解析・保守引き継ぎ
  • VB6保守、VBA・C#・Accessの機能追加・障害修正
  • COMコンポーネント・DB接続方式の見直し
  • VB6からC#・.NETへの段階的移行
  • 販売・在庫・仕入・発注管理、POS、画面・帳票の改修
  • Windows・Office更新への対応、ドキュメント整備
既存システムの改修を相談する
03 / DATA INTEGRATION

業務データ連携・バッチ処理開発

業務システム間のデータ連携を確実に実装

C#・SQL・Oracleなど、既存の技術環境に合わせて取込・変換・出力処理を実装します。連携先の仕様、データの整合性、失敗時の復旧方法を確認し、運用を見据えて設計します。

  • CSV・Excelデータの取込・出力・変換
  • DB間のデータ移行、件数・金額・整合性の照合
  • APIによる外部システム連携
  • 定期バッチ処理の開発
  • エラー処理・ログ出力・再実行処理
データ連携について相談する

要件整理・設計・開発・テスト・導入・保守の各工程も、必要な範囲で支援します。対応可否、費用、期間は内容を確認したうえで個別にご案内します。

// Process

ご依頼の流れ

SQL調査や一部分の改修でも、課題と作業範囲を整理し、進め方・契約条件を確認します。

  1. 01

    お問い合わせ

    対象システム、ご依頼したい作業、ご希望の時期を分かる範囲でお知らせください。

  2. 02

    作業内容のヒアリング

    対象環境、作業範囲、期間、作業方法（リモート・訪問）、連絡方法を確認します。

  3. 03

    NDA・資料確認

    必要に応じて秘密保持契約を締結し、仕様書やソースコードなどを確認します。

  4. 04

    対応方針・お見積りのご提案

    対応可否、作業範囲、検証方法、契約形態、概算費用、開始時期をご案内します。

  5. 05

    ご契約

    請負・準委任など、個別に合意した条件で契約を締結します。

  6. 06

    作業開始

    貴社の開発標準、連絡方法、管理ツールに合わせて作業を開始します。

  7. 07

    報告・レビュー・継続支援

    進捗と課題を共有し、レビューや次工程、保守・追加開発へつなげます。

オンラインでの事前打ち合わせ、画面共有、ソースコード・設計書の確認に対応しています。エンドユーザー企業様からの直接相談も承ります。
