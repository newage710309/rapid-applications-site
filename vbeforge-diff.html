// Freeware — VBE Add-in for VBA Developers

VBE Forge Diff無料

VBAソースを、フォルダや別のブックと比較

VBE（Visual Basic Editor）のメニューから、現在開いている VBA プロジェクトのソースを、 フォルダの .bas / .cls / .frm や、Excel で開いている別のブックと比べて、違いをモジュールごと・行ごとに表示します。 インポートする前の確認や、本番用と開発中のブックの見比べに。比較はプロジェクトもファイルも一切変更しません。

Windows 10 / 11 Excel 2016 以降 32bit / 64bit 両対応 管理者権限 不要 .NET Framework 4.8 MIT License
無料ダウンロード 使い方を見る

Version 1.0.0  /  ZIP 63 KB  /  2026.10.28 公開

書き出しには VBE Forge Export、取り込みには VBE Forge Import をご利用ください。

// Features

VBE Forge Diff の特長

「どこが違うのか」を、VBE の中で、何も書き換えずに確かめるためのアドインです

フォルダとも、別のブックとも比較

比較相手は、フォルダ直下の .bas / .cls / .frm（VBE Forge Export の出力先など）か、Excel で開いている別のブックの VBA プロジェクトから選べます。

モジュールごとに違いを一覧

「変更あり／種別が異なる／現在のみ／相手のみ／同一」をモジュールごとに一覧表示し、追加・削除の行数も並べます。最初は差分があるものだけを表示します。

行単位の差分を色分け表示

左右に並べる表示と上下1列の表示を切り替えられます。［前の差分］［次の差分］で変更箇所へすぐ移動できます。

差分の行から VBE の該当行へ

現在のプロジェクト側の行をダブルクリックすると、画面を閉じて VBE でそのモジュールの該当行を開きます。気になった箇所をそのまま直せます。

余計な違いは無視できる

改行コードの違いと先頭・末尾の空行は常に無視します。行末の空白と、VBE が自動で揃える識別子の大文字小文字の違いも、オプションで無視できます（既定は ON）。

読み取り専用・商用利用も無償

プロジェクトもファイルも書き換えません。差分は unified diff 形式でコピー・保存できます。管理者権限不要、32bit・64bit 両対応、MITライセンスのフリーソフトです。

比較元のブックを開き、VBE を開く

ブックを開いて Alt + F11 を押し、プロジェクトエクスプローラーで比較元（基準）にする VBA プロジェクトを選択します。別のブックと比べる場合は、そのブックも開いておきます。

2

アドイン → VBE Forge Diff

比較相手に「フォルダ」か「開いている別のプロジェクト」を選んで［比較］をクリックします。前回の比較相手を記憶しており、初回は Export の出力先が初期値になります。

3

一覧から差分を開く

モジュールの行をダブルクリックすると、行単位の差分が表示されます。赤は現在のプロジェクトにだけある行、緑は比較相手にだけある行です。

4

該当行へジャンプ、または差分を保存

現在のプロジェクト側の行をダブルクリックすると VBE でその行を開きます。［コピー］や［すべて保存...］で unified diff 形式の差分を残せます。

// Usage

導入と使い方

コマンド入力は不要です。同梱の install.bat をダブルクリックするだけで登録できます

1. インストール

ZIP を任意のフォルダへ展開し（例：C:\Tools\VBEForge.Diff\）、Excel をすべて終了してから install.bat をダブルクリックします。黒い画面が開くので、案内に従って Enter キーを押すと登録が始まり、 「インストールが完了しました。」と表示されたら閉じてください。Excel を起動して VBE（Alt + F11）を開くと、 アドイン メニューに VBE Forge Diff が追加されています。

登録後に展開したフォルダを移動しないでください。 移動した場合は install.bat を再度実行してください。 VBE Forge Export / Import と同じ PC に並べてインストールできます。

2. VBAプロジェクトへのアクセスを許可する

VBA プロジェクトのコードを読み取るために、Excel 側の信頼設定が必要です。設定後は Excel を再起動してください。

Excel の設定 
[ファイル]
 → [オプション]
 → [トラストセンター]
 → [トラストセンターの設定]
 → [マクロの設定]
 → 「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」にチェック

設定が無効な場合、本アドインはこの手順を案内するメッセージを表示して安全に終了します。

3. 比較相手を選ぶ

VBE（Alt + F11）で比較元のプロジェクトを選択し、アドイン → VBE Forge Diff をクリックします。 最初のダイアログで指定できる内容は次の通りです。

項目内容
フォルダ比較するフォルダを直接入力するか「参照...」で選択します。前回のフォルダを記憶し、初回は VBE Forge Export の出力先を初期値にします。
開いている
別のプロジェクト		Excel で開いている別のブックを一覧から選びます。保存していないブックと、パスワードで保護されたプロジェクトは表示されません。

無視する		行の末尾にある空白・タブの違いを差分として扱いません（既定は ON）。

違いを無視する		VBE が自動で揃える識別子の表記（Dim i と Dim I など）の違いを差分として扱いません（既定は ON）。

4. 一覧と差分を見る

［比較］をクリックすると、モジュールごとの比較結果が一覧で表示されます。行をダブルクリック（または［差分を表示］）すると、 そのモジュールの行単位の差分が開きます。差分画面では「左右に並べる」「上下 1 列」を切り替えられ、 ［前の差分］［次の差分］で変更箇所へ移動できます。

状態意味
変更あり両方にあり、コードが異なる
種別が異なる名前は同じだが、標準モジュールとクラスなど種別が違う
現在のみ現在のプロジェクトにだけある
相手のみ比較相手にだけある
同一コードが一致する
比較しないフォルダ内で同じモジュール名のファイルが重複している（2つ目以降）

モジュールは名前で対応付けます。フォルダ側の名前はファイル名ではなくファイル内の Attribute VB_Name から決まります（VBE 標準のインポートと同じ）。 ThisWorkbook や Sheet1 などのドキュメントモジュールは、コード名で対応付けてコード部分を比べます。

5. 該当行へのジャンプと差分の保存

差分画面で現在のプロジェクト側の行をダブルクリックすると、画面を閉じて VBE でその行を開きます。 ［コピー］は表示中のモジュールの差分を、一覧の［すべて保存...］はすべての差分を、unified diff 形式で出力します。

比較しないもの

比較するのはコードだけです。UserForm のデザイン（.frx）、参照設定、プロジェクトのプロパティは比較しません。 モジュール先頭の Attribute 行（VB_Name など）も、コードウィンドウに表示されない部分のため比較しません。 差分の反映（取り込み）は行いません。フォルダの内容をブックへ取り込むには VBE Forge Import をご利用ください。

アンインストール

Excel をすべて終了してから uninstall.bat をダブルクリックします。 展開したフォルダは手動で削除してください。ログと設定は %LOCALAPPDATA%\VBEForge\ に残るため、不要な場合は削除してください （VBE Forge シリーズの他の製品と共用です。他の製品も使っている場合は残してください）。 レジストリはインストール時に書き込んだキーのみを削除し、他のソフトウェアには影響しません。

うまく動かないとき

メニューに表示されない場合は、Excel を完全に終了してから登録し直してください。 VBE の アドイン → アドイン マネージャー に VBE Forge Diff があるか確認し、「ロード/アンロード」にチェックを入れてください。 動作ログは %LOCALAPPDATA%\VBEForge\Logs\VBEForge_yyyyMMdd.log に記録されます。
